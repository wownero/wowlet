# Wowlet

Wowlet is a Wownero desktop wallet for Linux, macOS and Windows, built with C++ and
Qt. It is based on [Feather Wallet](https://github.com/feather-wallet/feather).

## Download

Download Wowlet and its signed release hashes from
[Wowlet releases](https://github.com/wownero/wowlet/releases). The desktop wallet
link on [wownero.org](https://wownero.org/) also leads there.

## Development

The application includes an offline documentation browser under Help. Its guides
are generated by `contrib/docs/generate.py` from the Feather documentation submodule.
Wowlet-specific guides in `contrib/docs/overrides` take precedence over upstream
guides with the same filename. Edit those sources, then regenerate; files under
`src/assets/docs` are generated and must not be edited directly.

Run the documentation regression checks with `make check`. The inherited build
instructions are in [HACKING.md](HACKING.md).
